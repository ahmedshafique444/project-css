# project-css

This project is a simple **HTML & CSS website** that showcases the history and major milestones of space exploration.  
It includes a **homepage** with highlights and a **timeline page** with key events in chronological order.

---

## 📂 Project Structure

```
├── index.html        # Homepage - Introduction & highlights of space exploration
├── timeline.html     # Timeline page with major events
├── about.html        # (Optional) About page - add project or author details
├── styles.css        # Main stylesheet for styling the website
├── images/           # Folder containing project images
│   ├── sputnik1.jpg
│   ├── apollo11.jpg
│   ├── perseverance.jpg
│   ├── gagarin.jpg
│   └── iss.jpg
└── README.md         # Project documentation
```

---

## 🌌 Features

- **Responsive Design** – Works on desktop and mobile.
- **Homepage** – Overview of space exploration milestones.
- **Timeline Page** – Key events such as Sputnik, Apollo 11, ISS, and Mars missions.
- **Images & Cards** – Visual representation of events for better engagement.
- **Reusable CSS** – Centralized styles for consistent layout.

---

## 🖥️ How to Run

1. Download or clone the project:
   ```bash
   git clone <your-repository-url>
   ```
2. Open `index.html` in your browser.
3. Navigate through the site using the navigation bar.
